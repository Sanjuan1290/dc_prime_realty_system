# Binary media referenced but not embedded in AllCodes(4).txt

The source export supplied URLs for these assets, **not their bytes**. This package intentionally omits these media files instead of shipping corrupt zero-byte files or overwriting production photographs.

If your original Git working tree already contains the assets, **keep those existing files**. To restore from the repository URLs on a computer with Internet access, run `python _delivery/restore_media_assets.py --restore` from the package root. It does not overwrite an existing file unless `--overwrite` is specified.
